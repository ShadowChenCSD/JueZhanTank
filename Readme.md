# 决战坦克 v1.2.3

## What is new in v1.2.3 ?

1. Map文件夹：更换了背景图片，并将所有背景图片设置为640x480的尺寸。
2. Map文件夹：更新了进场坦克图片，去除了原坦克图像的黑边，并将所有坦克图片设置为640x480的尺寸。
3. Map文件夹：Title.jpg -> 去除了水印。
4. Map文件夹：Hiscore.jpg -> 去除了水印。
5. Map文件夹：CookieHelp.jpg -> 重绘了在线帮助，录入了全部的25种宝物。
6. MapEditor.exe -> 修改了启动时的载入图像，去除了下方的水印。
7. MapEditor.exe -> 固定了Stage Manager的窗口大小，并重新调整了下方按钮的大小和位置。
8. MapEditor.exe -> "Save T.."和"Load T.."修改为"Save TXT"和"Load TXT"，他们可以对某一单独关卡进行存储和读取。
9. Stage.dat -> 删除了原有的52张地图，更新了红白机的BattleCity的地图，一个历程合计35个关卡，另设有起始关和最终关，关卡数：1+35*2+1。
10. Tank.exe "标题" -> 加入了改编者和修改日期。
11. Tank.exe "封面图像" -> 去除了下方的水印。
12. Tank.exe "重返战场" -> 固定了窗口大小，并重新调整了下方按钮的大小和位置。
13. Tank.exe "游戏选项" -> 更新了右下角的修订时间、修订地点的标记。
14. Tank.exe "游戏选项：杂项" -> 更改了难度描述的文字。
15. Tank.exe "游戏选项：控制" -> 测试了微软的XBOX手柄功能，单人/双人均可。
16. Tank.exe "游戏选项：关于" -> 增改了改编者及改编者的联系方式。
17. Tank.exe -> 修改了初始坦克数，由原有的“出场1台、预备3台”改为“出场1台、预备10台”。
18. Tank.exe -> 修改了部分宝物的文字说明。
19. Tank.exe -> 修改了部分初始特殊弹药的库存。
                          爆破弹，子弹量由初始20发，改为初始40发，子弹总量由满载100发，改为满载200发。
                          地雷，子弹量由初始15发，改为初始20发，子弹总量由满载75发，改为满载100发。
20. 测试了局域网内的联机功能（基于Internet的TCP/IP协议），可支持局域网内的双人作战。
21. 增加了"禁用3D加速.reg" -> 开始游戏前运行"禁用3D加速"，否则全屏游戏时会闪屏。
22. 增加了"启用3D加速.reg" -> 结束游戏后记得"启用3D加速"，否则电脑里的其他应用可能会无法正常工作。
23. 增加了"ReleaseNote.txt"，记录软件更新历史。

## What is new in v1.2.2 ?

 1、增加了存档、读档功能，存档是自动的；
 2、降低了游戏难度，其中：敌方布雷车的布雷频率降低到 20 %；
 3、调整了子弹速度，其中：穿甲弹在发射初期速度较慢；
 4、修正了游戏速度问题；
 5、修正了奖励分数问题；
 6、处理了背景图案，普遍把亮度和对比度降低了；
 7、增加了 6 张地图，共 52 张地图。

## What is new in v1.2.0 ?

 1、增加了一种新的加强武器（Mine）；
 2、增加了两种新的辅助选件（Shield Of Moon，Memory of Sea）；
 3、增加了五种新的宝物；
 4、增加了八种新的敌人；
 5、地图总数增加到 46 ；
 6、地图的分布与难度有关，部分关卡要通过了“极困难”级别才会出现；
 7、某些地图的某些位置有隐藏宝物，打掉该砖块就会出现；
 8、佩戴 Memory of Sea 的敌人可以获得除了“分数”以外的任何宝物；
 9、火焰被分成了三种颜色，“红”（对敌我有损）、“橙”（仅对我方有损）、“黄”（仅对敌方有损）；
10、装甲上限增加到 8，子弹数量上限增加到 5 倍基数；
11、细节改良，比如：可以在1.5sec内回避突然出现在你头顶的宝物，免得飞来横祸；敌人比你晚出现4sec，于是你可以占领有利位置；续关的时候，会给予额外的支持和保护。

对 Mine 的补充说明：
    a) [ AmphiTank ], 可以在水上布 Mine ；
    b) [ AntiSkid ], 可以在敌方 LV0～LV2 的 Mine 上安全行走（LV3 的 Mine 是有彩环的）；
    c) [ Shield of Moon ], 可以安全去除敌方 LV0 的 Mine；
    d) [ Memory of Sea ], 可以免坐飞机之险，免除慢行之苦（前提是你有足够的装甲或者无敌）；
    e) 爆破弹可以引爆等于或低于自己等级的 Mine；

## What is new in v1.1.1 ?

1、改正了联网传输和联网选项的两个小Bug。
2、减少了地图传输的网络负荷。
3、联网时，如果有玩家进入或退出游戏，系统会提示信息。
4、在默认状态下，自动暂停游戏的功能是关闭的。可以按[F8]切换开关或者按[F9]看性能选项下的“自动暂停游戏”。（这样是为了在联网主机玩家处理其他事情的时候，客户机不会自动暂停）

注：[F1]、[F4]...[F12]上都定义了某些功能，请不要用于游戏控制。
      [F1]  在线帮助；
      [F4]  全屏/窗口模式切换；
      [F9]  设置选项；
      [F10] 强制刷新画面；
      [F11] 隐藏/显示信息；
      [F12] 发送信息
